# 🛒 E-Commerce Sales Analysis | SQL & Power BI #

## 📌 Project Overview

This project analyzes e-commerce sales data using **MySQL and Power BI** to explore sales performance, product demand, revenue trends, and regional performance.

SQL is used to query and aggregate sales data, while Power BI transforms the results into an interactive dashboard for business reporting and decision-making.

## 🎯 Project Objectives

- Analyze monthly revenue trends.
- Identify the regions with the highest number of items sold.
- Find the top 5 best-selling products by quantity.
- Identify the product categories generating the highest revenue.
- Compare revenue across cities.
- Analyze revenue across different price categories.
- Explore sales performance using interactive dashboard filters.

## 🛠️ Tools & Technologies

## 📂 Dataset Overview

The project uses two tables:

**1. `ecommerce_orders`**
- Order ID
- Order date
- Product
- Category
- Price
- Quantity
- Region
- Customer name

**2. `ecommerce_customers`**
- Customer name
- City
- Other customer attributes, if available

The orders table contains sales-related information, while the customers table provides customer details for geographic analysis.

## 🔍 SQL Business Analysis

### 1. Regional Sales Performance
Identified regional item sales by calculating the total quantity sold in each region.

**SQL concepts:** `SUM()`, `GROUP BY`, `ORDER BY`

### 2. Monthly Revenue Trends
Calculated monthly revenue using product price and quantity, grouped by order month.

**Revenue formula:**

`Total Revenue = Price × Quantity`

**SQL concepts:** `SUM()`, `DATE_FORMAT()`, `GROUP BY`

### 3. Top 5 Best-Selling Products
Ranked products based on total quantity sold to identify the five highest-volume products.

**SQL concepts:** Aggregation, `ORDER BY`, `LIMIT`

### 4. Revenue by Product Category
Compared total revenue generated by different product categories.

**SQL concepts:** `SUM()`, `GROUP BY`, `ORDER BY`

### 5. Revenue by City
Joined customer and order data to calculate total revenue for each city.

**SQL concepts:** `INNER JOIN`, `GROUP BY`, aggregate functions

## 📊 Power BI Dashboard

The Power BI report contains the following visualizations:

- **Monthly Revenue Trend:** Tracks revenue over time using a line chart.
- **Product Sales Analysis:** Compares products by quantity sold using a bar chart.
- **Category Revenue Analysis:** Shows revenue distribution across product categories using a donut chart.
- **City Revenue Analysis:** Compares revenue across cities using a column chart.
- **Price Category Analysis:** Compares revenue across price categories.
- **Regional Sales Map:** Visualizes revenue by region geographically.

### Interactive Filters

The dashboard includes slicers for:

- Region
- Product category
- Month
